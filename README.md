Проект: сайт вопросов и ответов по типу Stack Overflow. Пользователи задают вопросы, отвечают на них, ставят лайки и отмечают верный ответ.

## ДЗ 1. Вёрстка статического сайта

Вся вёрстка лежит в папке `public/`, статика в `public/static/`:

- `public/static/css/` - Bootstrap 5.3.3 и свой `style.css` (подключается после бутстрапа)
- `public/static/js/` - Bootstrap JS
- `public/static/img/` - аватарки и favicon

Bootstrap лежит локально, CDN не используется.

### Как открыть

Склонировать репозиторий и открыть `public/index.html` в браузере. Ничего устанавливать не нужно.

Можно и через локальный сервер:

```
cd public
python -m http.server 8000
```

и открыть http://localhost:8000

### Страницы

| Файл | Что там |
|---|---|
| `base.html` | общий каркас: шапка, правая колонка, футер |
| `index.html` | список новых вопросов с пагинацией |
| `hot.html` | популярные вопросы |
| `tag.html` | вопросы по тегу |
| `question.html` | страница вопроса с ответами и формой ответа |
| `ask.html` | форма нового вопроса |
| `login.html` | вход |
| `signup.html` | регистрация |
| `profile.html` | настройки профиля |

На страницах входа и регистрации в шапке показан вариант для неавторизованного пользователя, на остальных для авторизованного.
